# WeatherApp

Учебный Java-проект для получения метеорологических данных из API Яндекс Погоды.

## Возможности

- Получение прогноза погоды по географическим координатам.
- Вывод полного JSON-ответа API.
- Отображение текущей температуры.
- Расчёт средней дневной температуры за заданное количество суток.

## Технологии

- Java 17
- Maven
- Jackson
- Java HTTP Client
- Yandex Weather API

## Настройка

Для запуска необходимо получить API-ключ Яндекс Погоды и задать переменную окружения `YANDEX_WEATHER_API_KEY`.

В Windows PowerShell для текущего терминала:

```powershell
$env:YANDEX_WEATHER_API_KEY = "ВАШ_API_КЛЮЧ"
```

Затем запустите `WeatherApp` из IntelliJ IDEA.

## Параметры запроса

- Координаты: Санкт-Петербург (`lat=59.93`, `lon=30.31`).
- Количество суток прогноза: `limit=5`.

API-ключ не хранится в исходном коде.
